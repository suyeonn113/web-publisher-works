# FRAGFARM MOBILE

빈티지 패션 브랜드의 감성을 유지하면서 상품 탐색부터 주문, 회원, 리뷰와 문의까지 연결한 PHP 기반 모바일 커머스 리디자인입니다.

- Live: https://suyeonn.dothome.co.kr/fragfarm-mobile/index.php
- Stack: PHP, MySQL, JavaScript, CSS

## 프로젝트 개요

단순 상품 랜딩 페이지가 아니라 상품 목록·검색·상세, 장바구니, 위시리스트, 주문, 회원 기능과 게시판 상호작용까지 이어지는 모바일 쇼핑 흐름을 구현했습니다. 사진 중심의 브랜드 인상은 유지하면서 가격, 옵션과 주요 액션이 작은 화면에서도 빠르게 읽히도록 정보 위계를 재정리했습니다.

## 문제와 개선 방향

### 1. 브랜드 이미지와 구매 정보의 우선순위가 충돌함

- 상품 카드의 이미지, 이름·가격, 리뷰와 장바구니·위시 액션을 역할별 영역으로 나눴습니다.
- NEW·SALE·SOLD OUT 상태를 서로 다른 라벨과 텍스트로 구분했습니다.
- 리뷰 영역을 사진 나열이 아닌 브랜드 아카이브처럼 보이도록 타이포와 여백을 정리했습니다.

### 2. 목록 상태가 페이지 이동 후 유지되지 않음

- category, sort, page와 view query를 정규화했습니다.
- 필터, 품절 후순위 정렬, 선택 정렬과 페이지네이션을 순서대로 계산합니다.
- 1열·2열 보기와 현재 목록 상태를 URL에 남겨 새로고침과 공유 후에도 유지되게 했습니다.

### 3. 모바일 쇼핑 흐름이 상품 상세에서 끝남

- 옵션 선택, 장바구니, 위시리스트, 주문서와 주문 완료를 연결했습니다.
- 마이페이지에서 주문 상태, 배송지, 쿠폰, 적립금과 작성한 리뷰·댓글·문의를 확인할 수 있게 했습니다.
- 리뷰와 문의의 작성·수정·삭제를 서비스 함수와 action PHP로 분리했습니다.

## 핵심 사용자 흐름

1. 홈에서 컬렉션, 신상품, 세일과 리뷰 아카이브를 확인합니다.
2. 카테고리, 정렬, 보기 방식과 페이지 이동으로 상품을 탐색합니다.
3. 영문 상품명 또는 한글 유사어로 상품을 검색합니다.
4. 상세 화면에서 옵션과 재고를 확인하고 장바구니 또는 위시리스트에 추가합니다.
5. 장바구니의 수량과 선택 상품 합계를 확인한 뒤 주문 흐름으로 이동합니다.
6. 마이페이지에서 주문과 회원 정보를 확인하고 리뷰·문의 콘텐츠를 관리합니다.

| 화면 | 주요 구현 | 확인 포인트 |
| --- | --- | --- |
| Home | 히어로, 신상품, 세일, 리뷰 아카이브, 브랜드 소개 | 브랜드 감성과 모바일 정보 위계 |
| Product list / Search | 카테고리, 정렬, 1·2열 보기, 페이지네이션, 한글 alias 검색 | URL에 유지되는 탐색 상태 |

| Cart / Order | 상품 선택, 수량, 삭제, 합계, 주문서·완료 | 같은 저장 데이터를 사용하는 쇼핑 흐름 |

## 구현 포인트

- PHP include로 head, header, footer와 상품 카드를 공통화했습니다.
- 상품 데이터는 `includes/data`, 목록·검색·피드백 로직은 `includes/services`로 분리했습니다.
- 한글·영문 카테고리 alias map으로 `pants/바지`, `skirt/치마`, `top/상의` 같은 검색 표현을 함께 지원합니다.
- `shop-storage.js`에서 장바구니, 위시리스트와 데모 주문 데이터를 같은 형태로 정규화합니다.
- core token, typography와 color 파일로 간격, 컨트롤 높이, 색상과 상태 스타일을 관리합니다.

## 접근성

- 메뉴와 본문 바로가기 링크를 첫 탐색 항목으로 제공합니다.
- 카테고리 선택 후 상품 목록 제어 영역으로 포커스를 복원합니다.
- 다이얼로그가 열리면 내부로 포커스를 옮기고, 닫으면 실행 버튼으로 돌려보냅니다.
- 리뷰 자동 흐름은 마우스와 키보드 포커스 시 멈추며 `prefers-reduced-motion` 환경에서는 실행하지 않습니다.
- 토스트와 상태 변화는 `role="status"`와 `aria-live`로도 전달합니다.

## 로컬 실행

PHP 8.x 환경에서 프로젝트 루트를 문서 루트로 지정합니다.

```bash
php -S 127.0.0.1:8080 -t .
```

회원, 주문과 게시판의 DB 기능을 확인하려면 `database/`의 SQL을 적용하고 로컬 DB 연결 정보를 설정해야 합니다. DB 연결이 없는 환경에서도 주요 포트폴리오 화면과 일부 데모 상태를 확인할 수 있습니다.

## 구현 범위

실제 PG 결제, 소셜 로그인과 외부 간편결제는 포함하지 않습니다. 운영 쇼핑몰 전체가 아니라 핵심 쇼핑·회원·게시판 흐름을 동작 가능한 데모로 구현한 비상업 포트폴리오입니다.
