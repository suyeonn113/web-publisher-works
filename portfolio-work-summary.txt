웹 퍼블리셔 포트폴리오 정리
작성일: 2026-07-07

목표
- 제출용 포트폴리오 기준으로 각 프로젝트의 강점, 완성본 설명 방향, 면접 포인트를 정리한다.
- 작업 환경 기록이나 처리 로그는 남기지 않는다.
- Codex 도움을 받은 코드도 내가 직접 설명할 수 있도록 공부 포인트를 기록한다.


전체 진행 순서

1. daisomall
- 현재 상태: 제출용 정리 확정 완료.
- 제출 방향: 홈+검색 중심의 상품 탐색 경험을 보여주는 커머스 퍼블리싱 프로젝트.
- 핵심 가치: 페이지 수를 넓히기보다 홈, 검색, 상품 카드, 카테고리, 기획전, 랭킹 흐름의 완성도를 높였다.
- 상세 정리 파일: daisomall-work-summary.txt

2. airseoul
- 현재 상태: 제출용 정리 확정 완료.
- 제출 방향: 항공권 검색/예약 흐름과 여행 정보 구조를 보여주는 대형 서비스형 포트폴리오.
- 핵심 가치: 검색 조건 입력, URL query 기반 결과, 날짜별 운임, 항공편/운임 선택, 여정 요약으로 이어지는 예약 탐색 흐름을 구현했다.
- 상세 정리 파일: airseoul-work-summary.txt

3. fragfarm-mobile
- 모바일 퍼블리싱과 상품 상세/회원 기능 흐름을 보여주기 좋다.

4. seoul-youth-center
- 기관 사이트 정보 구조와 신청 플로우를 보여주기 좋다.

5. book-log-app
- 아직 제작 중.
- 기능형 포트폴리오 후보로 남겨둔다.


공통 포트폴리오 체크리스트

디자인
- 첫 화면에서 프로젝트 성격이 바로 보이는가.
- 여백, 타이포, 카드, 버튼, 탭 스타일이 일관적인가.
- 캡처로 보여줄 대표 화면이 충분히 정돈되어 있는가.

접근성
- 키보드만으로 주요 기능을 사용할 수 있는가.
- focus-visible 스타일이 명확한가.
- 버튼과 링크 역할이 올바른가.
- heading 순서가 자연스러운가.
- 이미지 alt 정책이 일관적인가.
- 선택 상태가 시각적으로만 전달되지 않는가.

면접
- 프로젝트 범위를 한 문장으로 설명할 수 있는가.
- 기존 결과물의 부족한 점과 내가 개선한 점을 구체적으로 말할 수 있는가.
- 팀 프로젝트라면 내가 이해하고 개선한 부분을 구분해서 말할 수 있는가.
