# AIR SEOUL

항공권 검색 조건 입력부터 검색 결과 비교, 운임 선택과 여정 요약까지 연결한 React 기반 항공 서비스 리디자인입니다.

- Live: https://suyeonn.dothome.co.kr/airseoul/
- Stack: React, React Router, SCSS, Vite

## 프로젝트 개요

단순 랜딩 페이지가 아니라 항공권 예약, 예약 조회, 체크인, 스케줄, 변경·환불, 여행 정보, 이벤트와 브랜드 소개를 라우팅으로 나눈 서비스형 프로젝트입니다. 항공사 사이트 전체 메뉴를 복제하기보다 예약 탐색과 주요 여행 정보 흐름을 핵심 구현 범위로 정했습니다.

## 문제와 개선 방향

### 1. 검색 조건과 결과 화면이 분리되어 흐름이 끊김

- 출발지, 도착지, 날짜와 탑승객 조건을 URL query로 전달했습니다.
- 검색 결과 화면에서 query를 다시 읽어 사용자가 입력한 조건을 복원했습니다.
- 날짜별 운임, 가는편·오는편 항공편과 운임 선택을 한 흐름으로 연결했습니다.

### 2. 선택 정보가 여러 영역에 흩어짐

- `BookingSummaryAside`에서 선택 항공편, 탑승객과 총액을 함께 요약했습니다.
- 선택 전·후 상태와 가는편·오는편 단계를 구분해 다음 행동을 이해하기 쉽게 했습니다.

### 3. 탭과 날짜 선택에 많은 Tab 이동이 필요함

- 탭 그룹과 날짜별 운임에 roving tabindex 패턴을 적용했습니다.
- 그룹 안에서는 방향키와 Home/End로 이동하고, Tab은 다음 콘텐츠로 진행합니다.
- 운임 라디오 input에 포커스가 들어오면 카드 전체에 `focus-within` 표시가 나타나게 했습니다.

## 핵심 사용자 흐름

1. 홈 예약 패널에서 여정 유형과 검색 조건을 입력합니다.
2. URL query 기반 항공편 검색 결과로 이동합니다.
3. 날짜별 운임을 비교하고 가는편·오는편 항공편과 운임을 선택합니다.
4. 여정 요약에서 탑승객, 선택 항공편과 총액을 확인합니다.
5. 예약 조회, 체크인, 스케줄과 여행 정보 화면에서 후속 업무를 확인합니다.

## 핵심 화면

| 화면 | 주요 구현 | 확인 포인트 |
| --- | --- | --- |
| Home / Booking panel | 여정 유형, 공항, 날짜, 탑승객, 프로모션 코드 | 입력 상태와 팝업 포커스 흐름 |
| Flight search results | URL query 복원, 날짜별 운임, 항공편·운임 선택 | 검색 조건과 결과의 연결 |
| Booking summary | 선택 항공편, 탑승객, 총액 요약 | 선택 상태가 실시간으로 반영되는 구조 |
| Check-in / Schedule | 서비스별 입력·결과·상세 안내 | 공통 페이지 쉘과 콘텐츠 분리 |
| Baggage / Seat / Airport service | 탭, 표, 안내 카드 | 정보량이 많은 페이지의 가독성 |
| Event / Brand story | 목록·상세와 브랜드 콘텐츠 | 서비스형 라우팅의 확장 범위 |

## 구현 포인트

- `MainLayout`에 Header, Footer, 로그인 패널과 접근성 빠른 메뉴를 묶었습니다.
- `bookingPanelData`로 데이터성 설정을 분리하고 컴포넌트는 화면 상태와 이벤트 처리에 집중하게 했습니다.
- 검색 query 생성은 왕복과 편도 함수로 분리했습니다.
- SCSS foundation의 token, breakpoint와 mixin으로 색상, 여백, hover와 focus ring 기준을 통일했습니다.
- overflow로 outline이 잘리는 탭은 내부 `box-shadow` 방식의 포커스링으로 보완했습니다.

## 접근성

- 본문, 주요 메뉴와 푸터로 이동하는 접근성 빠른 메뉴를 제공합니다.
- 탭과 패널을 `aria-selected`, `aria-controls`, `aria-labelledby`로 연결했습니다.
- 예약 단계는 `aria-current="step"`, 선택 버튼은 `aria-pressed` 또는 `aria-selected`로 상태를 전달합니다.
- 로그인 패널은 dialog와 `aria-modal` 구조로 제공하고 장식 아이콘은 접근성 트리에서 제외했습니다.

## 로컬 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 코드 검사는 `npm run lint`로 확인할 수 있습니다.

## 구현 범위

실제 결제와 로그인 인증은 포함하지 않습니다. 일부 메뉴는 placeholder이며, 핵심 예약 탐색과 주요 여행 정보 페이지를 동작 가능한 포트폴리오 범위로 구현했습니다.
