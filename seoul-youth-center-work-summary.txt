seoul-youth-center 완성본 요약

포지셔닝
- "지역 청소년센터의 정보 탐색과 프로그램 신청 경험을 재구성한 공공기관 웹사이트 리디자인"으로 설명한다.
- 단순 기관 소개 사이트가 아니라 센터 안내, 청소년 프로그램, 평생교육, 시설 이용, 열린마당, 통합검색, 프로그램 신청과 신청내역 확인까지 연결한 서비스형 포트폴리오로 잡는다.
- 정보량이 많은 공공기관 사이트를 메뉴 위계, 공통 서브페이지 구조, 신청 흐름, 반응형 UI와 접근성 기준으로 다시 정리한 프로젝트라고 설명한다.
- airseoul이 예약 탐색 중심이고 daisomall이 상품 탐색 중심이라면, seoul-youth-center는 복잡한 기관 정보 구조와 서로 다른 프로그램 신청 흐름을 보여주는 프로젝트로 구분한다.

페이지 볼륨
- 홈, 센터 소개, 인사말, 시설 및 개요, 조직도, 찾아오시는 길, 청소년 활동 카테고리 12종, 청소년 프로그램 목록/상세/신청, 평생교육 안내/강좌/신청, 신청내역, 시설 이용 안내, 대관, 기관방문, 공지 목록/상세, 로그인, 통합검색으로 구성했다.
- 청소년 프로그램의 기존 통합 소개 페이지는 제거하고 각 활동 카테고리를 상위 서브메뉴로 올려 사용자가 원하는 분야로 바로 이동하게 했다.
- 프로그램 신청은 별도 메인 메뉴로 분리하고 청소년 프로그램 신청, 평생교육 프로그램 신청, 신청내역 확인을 한 흐름으로 묶었다.

대표 사용자 흐름
- 홈에서 센터 핵심 배너, 접수중 프로그램, 센터 소식과 일정, 활동사진, SNS 콘텐츠를 확인한다.
- 청소년 프로그램 메뉴에서 참여·수련·지역연계·학교연계 등 활동 분야를 선택하고 카테고리 설명과 프로그램을 확인한다.
- 프로그램 신청 메뉴에서 접수 가능한 청소년 프로그램을 필터링하고 상세 확인 후 신청한다.
- 평생교육 안내에서 접수 방법과 환불 기준을 확인하고 강좌 신청 페이지에서 종목·강습반·강습명을 탐색해 신청한다.
- 신청내역 확인에서 청소년 프로그램과 평생교육 프로그램 신청을 구분해 조회하고 상세·수정·삭제 흐름으로 이동한다.
- 통합검색에서 센터 안내, 프로그램, 평생교육, 이용 안내, 소식을 한 번에 검색한다.

면접 핵심 메시지
- "정보가 분산되어 있던 청소년센터 사이트를 사용자 목적 중심의 메뉴 구조로 재편하고, 프로그램 탐색부터 신청과 신청내역 확인까지 이어지는 흐름을 구현했습니다."
- "청소년 프로그램은 활동 카테고리를 메뉴 바로 아래로 올리고, 신청 기능은 독립 메뉴로 분리해 정보 탐색과 업무 행동의 위계를 구분했습니다."
- "청소년 프로그램과 평생교육 프로그램의 데이터와 신청 화면은 성격에 맞게 다르게 구성하되, 상단 메뉴와 신청내역 구조는 공통 기준으로 통일했습니다."
- "공지, 일정, 활동사진, SNS처럼 콘텐츠 성격이 다른 홈 섹션을 각각의 정보 밀도에 맞게 재배치하고 반응형 레이아웃을 정리했습니다."
- "스킵 링크, 실선 포커스링, 탭 키보드 이동, overflow 안의 포커스 표시, SNS 포커스 순환 오류를 점검해 키보드 접근성을 개선했습니다."


seoul-youth-center 기술 포인트

구조
- PHP include 구조로 헤더, 전역 메뉴, 좌측 서브메뉴, 상단 신청 메뉴, 푸터를 공통화했다.
- 페이지별 CSS를 분리하고 공통 컴포넌트 스타일과 페이지 전용 스타일의 역할을 구분했다.
- includes/data와 includes/functions에서 프로그램 데이터, 메뉴 데이터, 신청 처리에 필요한 함수를 관리한다.
- 청소년 프로그램 카테고리 페이지는 query parameter를 기준으로 카테고리별 설명과 프로그램 데이터를 렌더링한다.
- 통합검색은 여러 콘텐츠 데이터를 하나의 결과 구조로 합치고 카테고리 필터, 검색어 강조, 결과 없음 상태를 제공한다.

정보 구조
- 메인 메뉴는 청소년센터 안내, 청소년 프로그램, 평생교육 프로그램, 동그라미 학교, 이용 안내, 열린마당, 프로그램 신청으로 정리했다.
- 청소년 프로그램 아래에는 참여활동, 수련활동, 지역연계활동, 학교연계활동, 진로체험활동, 미래융합활동, 국제교류활동, 장애청소년활동, 특성화활동, 동그라미학교, 방과후아카데미, 청소년문화공간을 배치했다.
- 프로그램 신청은 시각적으로 구분되는 독립 메뉴이며 청소년 프로그램 신청, 평생교육 프로그램 신청, 신청내역 확인으로 구성했다.
- PC 메가메뉴, 모바일 메뉴, 좌측 서브메뉴에서 같은 메뉴 위계와 명칭을 유지했다.

청소년 프로그램 신청
- programs.php는 접수 가능한 프로그램만 보여주고 상태, 연령, 분야, 검색어 필터를 제공한다.
- 접수 상태 용어는 사용자에게 익숙한 "접수중"으로 통일했다.
- 카드에서 상세 페이지, 신청 폼, 신청 확인 흐름으로 이동한다.
- 접수 종료 프로그램은 신청 목록과 상세 신청 흐름에서 제외했다.
- 실제 접수 규모에 맞춰 데스크톱 4열 카드 레이아웃을 사용한다.

평생교육 신청
- lifelong-education-apply.php에서 종목, 강습반, 강습명을 기준으로 접수 가능한 강좌를 탐색한다.
- 강좌명, 장소, 종목, 강사, 요일·시간, 대상, 수강료, 정원, 접수 상태와 신청 버튼을 표로 제공한다.
- 강좌별 접수 인원을 진행 바로 시각화하고 프로젝트의 짙은 남색을 사용해 좌측 패널과 색상 체계를 맞췄다.
- 신청 폼과 actions/lifelong_application_create.php를 연결해 평생교육 신청 데이터를 저장한다.

신청내역과 데이터
- 청소년 프로그램과 평생교육 프로그램을 위아래 별도 표로 나눠 한 화면에서 확인하게 했다.
- 두 표는 프로그램명, 신청자, 연락처, 신청일, 접수상태, 바로가기 열 너비를 같은 그리드로 통일했다.
- program_type 컬럼으로 청소년 프로그램과 평생교육 신청을 구분한다.
- 신청 상세, 수정, 삭제 처리 흐름을 유지했다.

홈 화면
- 히어로는 하나의 이미지를 PC와 모바일에서 공용으로 사용하는 조건에 맞춰 서로 다른 콘셉트의 배너 5종으로 구성했다.
- 배너 이동 버튼은 이미지의 핵심 텍스트를 가리지 않도록 바깥쪽으로 배치하고 컨트롤러는 배너 기준 오른쪽에 정리했다.
- 접수중 프로그램은 6개 기준의 전시형 자동 슬라이드로 구성하고 좌우 한 장 이동 기능을 제공한다.
- 프로그램 포스터는 교육, 시민참여, 문화예술 등 주제별로 색상, 사진, 일러스트, 타이포 콘셉트를 다르게 제작했다.
- 센터 소식과 일정은 공지사항, 서울시정, 보도자료, 달력, 센터 일정을 하나의 큰 섹션 안에서 균형 있게 배치했다.
- 일정 수가 변해도 카드 위치와 양쪽 열 높이가 흔들리지 않으며 일정이 많을 때는 센터 일정 카드 안에서만 스크롤된다.
- 공지 제목은 한 줄 말줄임으로 처리해 콘텐츠 길이에 따라 레이아웃이 덜컹거리지 않게 했다.
- 활동사진은 데스크톱 콜라주와 작은 화면 3열 구조를 사용하고, 인생네컷 앨범 느낌의 배경으로 섹션을 구분했다.
- SNS는 대표 영상, 채널 탭, 게시물 그리드와 유관기관 보기로 구성하고 이미지 높이와 하단 정렬을 통일했다.

디자인 시스템
- 핵심 색상은 주황색과 짙은 남색이며, 주황색은 활성·행동·강조에 제한적으로 사용한다.
- 좌측 서브메뉴는 짙은 남색 제목 영역, 주황색 포인트 라인, 중립색 활성 배경으로 정리했다.
- 본문과 읽는 텍스트는 과도한 bold를 피하고 제목과 데이터 강조에만 높은 굵기를 사용한다.
- 카드 radius, 회색 테두리, 구분선, 버튼 높이와 focus ring을 공통 기준으로 맞췄다.
- 같은 카드 스타일을 반복하기보다 정보 성격에 따라 텍스트 목록, 단계형 절차, 표, 아이콘 목록을 선택해 단조로움을 줄였다.
- 넓은 화면에서는 콘텐츠 최대 폭과 타이포 크기를 확장하고, 기존 폭 이하에서는 원래 크기 체계를 유지하도록 반응형으로 조정했다.


seoul-youth-center 접근성 포인트

키보드 흐름
- 메뉴와 본문으로 바로 이동하는 스킵 링크를 제공한다.
- 전역 메뉴, 좌측 메뉴, 프로그램 카드, 상세 링크, 신청 폼의 Tab 이동 순서를 확인했다.
- SNS 탭에서 포커스가 무한 순환하던 문제를 수정하고 선택 탭, 카카오톡 채널, 영상, 게시물, 유관기관 보기 순서로 이동하게 했다.
- 탭 그룹 안에서는 좌우 방향키로 이동하고 Tab은 다음 콘텐츠로 진행한다.
- 동적으로 바뀌는 달력 일정에서도 키보드 포커스 구조가 유지되도록 했다.

포커스/시각 피드백
- 점선 대신 짙은 남색 실선 포커스링을 공통 기준으로 사용한다.
- overflow 컨테이너에서 outline이 잘리는 요소는 내부 box-shadow 방식으로 보완했다.
- 카드 링크의 가상 요소 포커스링이 부모 섹션 전체를 감싸던 문제는 카드에 position 기준을 추가해 카드 안에만 표시되도록 수정했다.
- hover와 focus를 구분하되, 선택 상태와 단순 hover가 혼동되지 않도록 색상과 선을 정리했다.

스크린 리더 정보
- 탭과 패널은 role, aria-selected, aria-controls, aria-labelledby로 연결했다.
- 아이콘만 있는 버튼에는 aria-label을 제공하고 장식 이미지는 aria-hidden 또는 빈 대체 텍스트로 처리했다.
- 검색 결과 수, 프로그램 상태, 현재 메뉴처럼 시각적으로 강조되는 정보도 텍스트로 전달한다.


seoul-youth-center 페이지 설명 포인트

index.php
- 히어로, 접수중 프로그램, 센터 소식과 일정, 활동사진, SNS를 연결한 메인 화면이다.
- 서로 다른 슬라이더와 동적 콘텐츠의 높이, 자동 재생, 키보드 이동을 함께 정리한 화면으로 설명하기 좋다.

youth-program-category.php
- 하나의 페이지 템플릿에서 query parameter에 따라 활동 분야 설명과 프로그램 목록을 바꿔 보여준다.
- 통합 소개 페이지를 없애고 카테고리별 정보 구조로 바꾼 핵심 사례다.

programs.php / program-detail.php
- 접수 가능한 청소년 프로그램을 필터링하고 상세 정보와 신청 행동으로 연결한다.
- 상태·연령·분야·검색어를 조합하는 탐색 UI와 4열 반응형 카드 구조를 설명할 수 있다.

lifelong-education-guide.php / lifelong-education-apply.php
- 접수 방법, 환불 기준, 준비 서류 같은 안내 정보와 실제 강좌 신청 화면을 분리했다.
- 정보형 페이지와 데이터 표 중심 업무 페이지를 같은 디자인 언어로 구성한 사례다.

applications.php
- 성격이 다른 두 프로그램 신청내역을 하나의 페이지에서 구분해 제공한다.
- 공통 열 그리드와 program_type 기반 데이터 구분을 설명할 수 있다.

search.php
- 여러 페이지의 콘텐츠를 통합 결과로 구성하고 카테고리 필터와 검색어 강조를 제공한다.
- mbstring 확장이 없는 환경에서도 기본 검색이 동작하도록 처리했다.

notices.php / notice-detail.php
- 필독 게시물을 목록 상단에 고정하고 상세 페이지의 분류, 제목, 등록일, 담당, 본문, 목록 이동을 공통 구조로 정리했다.
- 분류는 작은 뱃지가 아니라 제목 위 주황색 텍스트로 표시한다.

- includes/components/global-nav.php: 메인 메뉴와 메가메뉴 구조.
- includes/components/section-nav.php: 좌측 서브메뉴와 현재 메뉴 처리.
- includes/components/program-apply-nav.php: 독립된 프로그램 신청 상단 메뉴.
- includes/data/programs.php: 청소년 프로그램 데이터와 상태 구분.
- includes/data/youth-program-categories.php: 활동 카테고리 설명과 메뉴 연결.
- includes/functions/application.service.php: 청소년 프로그램 신청 처리.
- includes/functions/lifelong-education.service.php: 평생교육 강좌와 신청 처리.
- index.php, js/home-calendar.js, js/program-recommend.js, js/sns-tabs.js: 홈 동적 UI와 접근성 처리.
- search.php: 통합검색 데이터 구성, 필터, 검색어 강조.
- applications.php: program_type별 신청내역 분리와 공통 표 구조.

포트폴리오 설명 시 주의할 점
- 실제 기관 운영 시스템 전체를 구현했다고 말하지 않고, 기관 정보 구조와 프로그램 탐색·신청 경험을 중심으로 구현한 리디자인이라고 설명한다.
- 실결제, 본인인증, 관리자 페이지는 구현 범위가 아니며 신청 데이터의 등록·조회·수정·삭제 흐름 중심이라고 구분한다.
- 배너와 포스터는 시연용 콘텐츠이므로 실제 운영 시 담당자 검수와 최종 문구 확인이 필요하다.
- 서울시정, 보도자료, 카카오톡 채널 등 일부 외부 링크는 운영 URL 확정 후 교체해야 한다.
- 코드 상당 부분은 Codex 도움을 받았으므로 내가 직접 설명할 수 있는 구조, 접근성 개선, 정보 구조 결정 이유를 중심으로 말한다.


seoul-youth-center 배포 메모

- 운영 BASE_URL은 includes/config.php의 /seoul-youth-center 설정을 확인한다.
- 기존 데이터베이스에는 database/2026-07-22-add-program-type.sql을 적용해야 한다.
- assets/images의 신규 히어로 배너, 프로그램 포스터, 섹션 배경을 폴더 구조와 파일명 대소문자를 유지해 업로드한다.
- youth-program-introduction.php는 의도적으로 삭제했으며 배포된 주소가 아니므로 리다이렉트를 만들지 않는다.
- 배포 후 통합검색, 청소년/평생교육 신청, 신청내역 수정·삭제, 메인 슬라이더, 달력, SNS 키보드 이동, 모바일 메뉴를 확인한다.
- Lighthouse, axe 또는 KWCAG 점검 도구로 전체 페이지 자동 접근성 검사를 한 번 더 진행하는 것이 좋다.


seoul-youth-center 최종 정리 상태

- 기관 안내부터 청소년·평생교육 프로그램 신청과 신청내역 확인까지 제출용 서비스 흐름을 갖췄다.
- 청소년 프로그램의 활동 카테고리와 프로그램 신청 메뉴를 분리해 정보 구조를 명확히 했다.
- 홈의 배너, 접수중 프로그램, 소식·일정, 활동사진, SNS를 각 콘텐츠 성격에 맞게 재구성했다.
- 프로그램 신청 데이터는 청소년과 평생교육으로 구분하고 공통 신청내역 화면에 연결했다.
- 스킵 링크, 포커스링, 탭 키보드 이동, SNS 포커스 순환 오류를 정리했다.
- 배포 전 데이터베이스 마이그레이션, 신규 이미지 업로드, 외부 링크와 자동 접근성 검사를 최종 확인해야 한다.
