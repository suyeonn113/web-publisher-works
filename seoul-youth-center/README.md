# SEOUL YOUTH CENTER

복잡한 기관 정보를 사용자 목적 중심으로 재편하고, 청소년·평생교육 프로그램 탐색부터 신청 내역 관리까지 연결한 PHP 기반 공공 서비스 리디자인입니다.

- Live: https://suyeonn.dothome.co.kr/seoul-youth-center/index.php
- Stack: PHP, MySQL, JavaScript, CSS

## 프로젝트 개요

기관 소개 화면에 머무르지 않고 센터 안내, 청소년 프로그램, 평생교육, 시설 이용, 열린마당, 통합검색, 프로그램 신청과 신청내역 확인을 하나의 서비스 흐름으로 구성했습니다. 정보량이 많은 공공기관 사이트를 메뉴 위계, 공통 서브페이지 구조, 반응형 UI와 키보드 접근성 기준으로 다시 정리했습니다.

## 문제와 개선 방향

### 1. 프로그램 정보와 신청 행동이 여러 메뉴에 분산됨

- 청소년 활동 카테고리를 상위 서브메뉴로 올려 원하는 분야로 바로 이동하게 했습니다.
- 프로그램 신청을 독립 메뉴로 분리하고 청소년 프로그램, 평생교육과 신청내역을 한 흐름으로 묶었습니다.
- PC 메가메뉴, 모바일 메뉴와 좌측 서브메뉴에서 같은 위계와 명칭을 유지했습니다.

### 2. 서로 다른 프로그램 유형의 신청 구조가 섞임

- 청소년 프로그램은 상태·연령·분야·검색어 필터와 카드형 목록으로 구성했습니다.
- 평생교육은 종목·강습반·강습명 탐색과 시간, 대상, 수강료, 정원을 비교하는 표로 구성했습니다.
- 신청 데이터는 `program_type`으로 구분하고, 신청내역에서는 공통 열 구조로 확인하게 했습니다.

### 3. 콘텐츠가 많은 홈의 높이와 탐색 흐름이 불안정함

- 히어로, 접수중 프로그램, 소식·일정, 활동사진과 SNS를 콘텐츠 성격에 맞는 레이아웃으로 나눴습니다.
- 일정 수가 달라져도 양쪽 열 높이가 흔들리지 않게 하고, 많은 일정은 카드 내부에서만 스크롤되게 했습니다.
- SNS 탭에서 Tab 포커스가 갇히던 오류를 수정했습니다.

## 핵심 사용자 흐름

1. 홈에서 접수중 프로그램, 센터 소식, 일정, 활동사진과 SNS를 확인합니다.
2. 청소년 활동 분야를 선택해 카테고리 설명과 관련 프로그램을 탐색합니다.
3. 접수 가능한 프로그램을 필터링하고 상세 확인 후 신청합니다.
4. 평생교육 안내와 강좌 조건을 확인한 뒤 신청합니다.
5. 신청내역에서 청소년·평생교육 신청을 구분해 조회, 수정 또는 삭제합니다.
6. 통합검색에서 센터 안내, 프로그램, 이용 안내와 소식을 함께 찾습니다.

## 핵심 화면

| 화면 | 주요 구현 | 확인 포인트 |
| --- | --- | --- |
| Home | 히어로, 접수중 프로그램, 소식·일정, 활동사진, SNS | 서로 다른 동적 콘텐츠의 균형과 반응형 구성 |
| Youth program category | query 기반 활동 분야 설명과 프로그램 렌더링 | 카테고리 중심으로 재편한 정보 구조 |
| Program list / Detail / Apply | 상태·연령·분야·검색 필터와 신청 | 탐색에서 행동으로 이어지는 흐름 |
| Lifelong education | 안내 페이지, 강좌 비교 표, 신청 폼 | 정보형 페이지와 업무형 페이지의 구분 |
| Applications | 두 프로그램 유형의 신청내역, 상세·수정·삭제 | `program_type` 기반 데이터 분리 |
| Search | 통합 결과, 카테고리 필터, 검색어 강조 | 여러 콘텐츠 데이터의 통합 탐색 |

## 구현 포인트

- PHP include로 전역 메뉴, 좌측 서브메뉴, 신청 상단 메뉴와 Footer를 공통화했습니다.
- `includes/data`와 `includes/functions`에서 프로그램·메뉴 데이터와 신청 로직을 관리합니다.
- 카테고리 페이지는 query parameter에 따라 설명과 프로그램 목록을 바꿔 렌더링합니다.
- 통합검색은 여러 콘텐츠 데이터를 공통 결과 구조로 합치고 필터, 검색어 강조와 결과 없음 상태를 제공합니다.
- 주황색은 활성·행동·강조에 제한하고 짙은 남색을 구조와 포커스 표시의 기준으로 사용했습니다.

## 접근성

- 메뉴와 본문으로 이동하는 스킵 링크를 제공합니다.
- 탭 그룹 안에서는 방향키로 이동하고 Tab은 다음 콘텐츠로 진행합니다.
- overflow 컨테이너에서 잘리는 outline은 내부 `box-shadow` 포커스링으로 보완했습니다.
- 아이콘 버튼에는 `aria-label`, 장식 이미지에는 빈 대체 텍스트 또는 `aria-hidden`을 적용했습니다.
- 동적으로 바뀌는 달력 일정과 슬라이더에서도 버튼 이름과 키보드 탐색 순서를 유지합니다.

## 로컬 실행

PHP 8.x와 MySQL 환경에서 프로젝트 루트를 문서 루트로 지정합니다.

```bash
php -S 127.0.0.1:8080 -t .
```

신청 기능을 확인하려면 `database/seoul_youth_center_program_applications.sql`을 적용하고, 기존 데이터베이스에는 `database/2026-07-22-add-program-type.sql` 마이그레이션을 추가합니다. 로컬 경로가 다르면 `includes/config.php`의 `BASE_URL`도 함께 확인합니다.

## 구현 범위

실제 기관 운영 시스템 전체를 구현한 프로젝트가 아닙니다. 실결제, 본인인증과 관리자 기능은 제외하고 기관 정보 구조와 청소년·평생교육 프로그램의 탐색·신청·신청내역 관리 경험을 핵심 범위로 구현했습니다.
